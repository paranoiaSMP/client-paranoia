PARANOIACLIENT

Client Minecraft premium. Téléchargez, installez, jouez.

Télécharger pour Windows

Impossible de récupérer la version automatiquement. Voir toutes les versions

1

Téléchargez l'installeur. Un seul fichier, rien d'autre à installer : ni Java, ni Minecraft, ni le code source.

2

Lancez-le. L'installation prend quelques secondes et crée un raccourci sur le bureau.

3

Connectez-vous en Microsoft. Le launcher télécharge Java et Minecraft tout seul au premier lancement.

Avertissement Windows au premier lancement L'installeur n'étant pas encore signé, Windows peut afficher « Windows a protégé votre ordinateur ». Cliquez sur Informations complémentaires puis Exécuter quand même.

Configuration requise : Windows 10 ou 11 (64 bits) · compte Minecraft Java Edition
